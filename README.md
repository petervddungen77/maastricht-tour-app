# Maastricht Tour App

A digital tour platform for exploring the beautiful city of Maastricht.

## Balanced Scorecard

This project includes a comprehensive Balanced Scorecard framework for tracking strategic performance across four key perspectives:

- **Financial**: Revenue, profitability, and cost metrics
- **Customer**: User satisfaction, engagement, and growth
- **Internal Process**: Operational efficiency and quality
- **Learning & Growth**: Innovation and organizational capabilities

### Scorecard Files

- **[BALANCED_SCORECARD.md](BALANCED_SCORECARD.md)** - Main scorecard documentation with all KPIs, targets, and strategic initiatives
- **[balanced-scorecard-data.json](balanced-scorecard-data.json)** - Machine-readable data for tracking and automation
- **[SCORECARD_USAGE_GUIDE.md](SCORECARD_USAGE_GUIDE.md)** - Complete guide on how to use and maintain the scorecard

### Quick Start

1. Review the [Balanced Scorecard](BALANCED_SCORECARD.md) to understand strategic goals
2. Read the [Usage Guide](SCORECARD_USAGE_GUIDE.md) for instructions on updating metrics
3. Update metrics monthly in the JSON file
4. Track initiative progress quarterly

For detailed information on using the Balanced Scorecard, see the [Usage Guide](SCORECARD_USAGE_GUIDE.md).
